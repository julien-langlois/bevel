# API documentation

The API documentation is generated by rustdoc from the source, with every feature enabled.
Items that need a feature are marked with it.

| Crate | This site | docs.rs |
| --- | --- | --- |
| `bevel-theme` | [api/bevel_theme](api/bevel_theme/index.html) | [docs.rs/bevel-theme](https://docs.rs/bevel-theme) |
| `bevel-widgets` | [api/bevel_widgets](api/bevel_widgets/index.html) | [docs.rs/bevel-widgets](https://docs.rs/bevel-widgets) |
| `bevel-window` | [api/bevel_window](api/bevel_window/index.html) | [docs.rs/bevel-window](https://docs.rs/bevel-window) |
| `bevel-i18n` | [api/bevel_i18n](api/bevel_i18n/index.html) | [docs.rs/bevel-i18n](https://docs.rs/bevel-i18n) |
| `bevel-fonts-build` | [api/bevel_fonts_build](api/bevel_fonts_build/index.html) | [docs.rs/bevel-fonts-build](https://docs.rs/bevel-fonts-build) |

**This site** follows the `main` branch and is built for Linux. **docs.rs** has one page per
released version, built for Linux, macOS, Windows and the web where a crate has
platform-specific items (use the platform menu at the top of a docs.rs page).

To build the documentation locally:

```sh
cargo doc --workspace --all-features --no-deps --open
```
